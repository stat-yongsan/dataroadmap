# 엑셀 데이터 정제·검증 연구 메모 — Jev 적용 구상

정리일: 2026-10-24

엑셀을 계산 결과를 보관하는 파일에서, 재사용 가능한 데이터를 관리하는 구조로 바꾸기 위한 연구 메모다. 원하는 답을 먼저 정의하고 데이터 정제·검증·분석을 반복 가능한 작업으로 만드는 데 초점을 둔다.

## 연구 방향

1. **문제 정의:** 어떤 답과 의사결정이 필요한지 먼저 정한다.
2. **데이터 구조 파악:** 한 행의 의미, 열 이름, 자료형, 단위, 업무 키와 출처를 확인한다.
3. **정제 후보 구성:** 형식 통일, 텍스트 분리, 중복 확인, 결측 처리와 이상치 점검 등 필요한 작업을 고른다.
4. **실행·검증:** 원본을 보존하고 처리 전후의 건수·오류·합계와 변환 이유를 확인한다.
5. **분석·재사용:** 크기·추세·비교·상관에 관한 질문을 숫자·맥락·의사결정 제안으로 연결하고, 검증한 절차를 반복 업무의 자산으로 남긴다.

## Jev 적용 구상

이 메모를 기존 [데이터 활용 로드맵](../../README_KO.md)의 다음 작업 선택 흐름에 연결한다.

- 코드는 데이터의 현재 상태를 측정하고, 필수 입력과 실행 조건을 확인해 허용 후보를 만든다.
- Jev는 상태 요약과 후보를 받아 다음에 수행할 작업을 선택한다.
- 코드는 등록된 작업을 실행하고 결과를 검증한다. 새 상태에서 다음 작업을 다시 선택한다.
- 계산·행 변경·확정 조건 검사는 코드가 수행한다. Jev의 판단 점수나 확신을 검증된 정확도·성공률로 해석하지 않는다.
- 연구 메모의 아이디어와 이미 구현된 기능은 별개다. 이 문서를 추가했다고 새로운 실행기나 실제 Jev 호출이 구현·검증된 것은 아니다.

## 수치와 검증 상태

아래 원문의 ‘1시간 → 10초’, ‘전처리가 90%’, ‘정제 5분’, ‘1,000건’은 강의·연구 구상을 적은 표현이다. 비교 실험의 조건·반복 측정·검증 결과가 이 메모에 없으므로 실측 성과나 보장된 효과로 인용하지 않는다.
