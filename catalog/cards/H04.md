#### H04 · 누적합·잔액 계산

**환경: L — 로컬 자료 처리**

- **입력 예제:** 기초잔액100, 입고50, 출고30의 순서 있는 이력을 둔다.
- **변환·출력 계약:** 확정된 시간·동률 순번으로 누적 잔액을 계산한다.
- **성공 기준:** 잔액 흐름은 100→150→120이며 최종120이다.
- **실패·경계 실험:** 동일 시각 거래의 순서가 필요한 경우 안정된 순번을 요구한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 H04만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
