#### H09 · 현금흐름의 시간가치

**환경: L — 로컬 자료 처리**

- **입력 예제:** 초기지출 -100, 1기간 후 수입110, 기간 할인율10%를 둔다.
- **변환·출력 계약:** 시점0 현금흐름을 별도 처리하여 할인현재가치 합을 계산한다.
- **성공 기준:** 순현재가치는 허용오차1e-9 이내0이다.
- **실패·경계 실험:** 월 단위 현금흐름에 연이율을 그대로 넣는 단위 오류를 검출한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 H09만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
