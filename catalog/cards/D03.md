#### D03 · 중복 키 검출

**환경: L — 로컬 자료 처리**

- **입력 예제:** id=[R001,R001,R002], amount=[100,200,300]을 준비한다.
- **변환·출력 계약:** 업무 키별 개수와 중복 그룹의 모든 원본 행을 보고한다.
- **성공 기준:** 중복 그룹 1개, 관련 행 2개다.
- **실패·경계 실험:** 완전히 같은 행과 같은 키지만 값이 다른 행을 구분하고 이 단계에서 삭제하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 D03만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
