#### A05 · 압축파일에서 자료 꺼내기

**환경: L — 로컬 자료 처리**

- **입력 예제:** ZIP 안에 dept/a.csv, dept/b.csv와 설명.txt를 넣는다.
- **변환·출력 계약:** 허용 확장자만 작업 폴더 안에 해제하고 추출 목록을 반환한다.
- **성공 기준:** CSV 2개만 추출되고 상대경로가 보존된다.
- **실패·경계 실험:** ../outside.csv 항목을 넣으면 작업 폴더 밖에 쓰지 않고 해당 압축파일을 거부한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 A05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
