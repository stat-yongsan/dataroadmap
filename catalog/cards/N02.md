#### N02 · 보고서용 정적 차트 생성

**환경: L — 로컬 자료 처리**

- **입력 예제:** 부서A300,B200,C500을 둔다.
- **변환·출력 계약:** 같은 디자인 설정으로 막대차트를 SVG 또는 PNG로 렌더링한다.
- **성공 기준:** 세 값과 단위가 정확하고 한글 글꼴·축·라벨이 잘리지 않는다.
- **실패·경계 실험:** 0 기준을 벗어난 축이나 다른 단위 혼합이 해석을 왜곡하지 않도록 확인한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 N02만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
