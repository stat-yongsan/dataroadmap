#### Q02 · 문장에서 구조화된 필드 추출

**환경: AI — 모델 처리 · mock과 실제 모델을 구분**

- **입력 예제:** 문장 9월3일 엑셀교육에3명 신청과 기준연도2026을 둔다.
- **변환·출력 계약:** 날짜·프로그램·인원과 각 값의 원문 근거를 JSON 스키마로 추출한다.
- **성공 기준:** 2026-09-03,엑셀교육,3이 나오며 연도는 기준값에서 보충했음을 표시한다.
- **실패·경계 실험:** 없는 전화번호를 지어내지 않고 null로 남긴다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 Q02만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
