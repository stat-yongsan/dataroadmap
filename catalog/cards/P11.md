#### P11 · 출처·실행 이력 추적

**환경: L — 로컬 자료 처리**

- **입력 예제:** 파일2개에서 가져온3행으로 합계1개를 만드는 예제를 둔다.
- **변환·출력 계약:** 입력 해시·원본 행키·설정·코드버전·단계·시간·상태를 연결해 기록한다.
- **성공 기준:** 결과 합계에서 원본3행과 적용 규칙을 추적할 수 있다.
- **실패·경계 실험:** 로그에 비밀키나 원문 개인정보를 그대로 남기지 않으며 실패 로그도 보존한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P11만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
