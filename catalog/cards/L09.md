#### L09 · 데이터 모델 관계·측정값

**환경: N — Excel 또는 지원 엔진 필요**

- **입력 예제:** 부서 차원D01=교과,D02=비교과와 사실표D01 100·200,D02 300을 둔다.
- **변환·출력 계약:** 사용 가능한 Excel 데이터 모델에서 관계와 합계 측정값을 정의한다.
- **성공 기준:** 전체600, 부서 교과300이며 관계 방향과 키 규칙을 기록한다.
- **실패·경계 실험:** 일반 워크시트 집계로 대체했으면 데이터 모델 실습 완료로 표시하지 않는다.
