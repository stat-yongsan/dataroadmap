#### M05 · 시트 구성·복제 관리

**환경: L — 로컬 자료 처리**

- **입력 예제:** Template 시트1개와 요청 부서명 교과·비교과를 둔다.
- **변환·출력 계약:** 지원되는 요소를 보존하며 부서별 시트를 복제하고 이름·순서를 설정한다.
- **성공 기준:** Template을 유지한 채 교과·비교과 시트가 생성된다.
- **실패·경계 실험:** 시트명 금지문자·길이·동명 충돌과 복제되지 않는 개체를 확인한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 M05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
