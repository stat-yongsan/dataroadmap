#### L03 · 계산 결과를 값으로 고정

**환경: N — Excel 또는 지원 엔진 필요**

- **입력 예제:** 재계산 완료한 B2=2,C2=3000,D2=B2*C2 파일을 준비한다.
- **변환·출력 계약:** 값 전용 배포 사본을 만들되 원본의 수식은 보존한다.
- **성공 기준:** 사본 D2=6000이며 수식이 없고 원본에는 수식이 남는다.
- **실패·경계 실험:** 캐시가 비었거나 오래되었으면 L02를 수행하기 전까지 값을 확정하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 L03만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
