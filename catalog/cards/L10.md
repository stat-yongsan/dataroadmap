#### L10 · 외부 통합문서 링크 관리

**환경: N — Excel 또는 지원 엔진 필요**

- **입력 예제:** source.xlsx의Data!B2=100을 target.xlsx에서 참조하게 한다.
- **변환·출력 계약:** 링크 대상·갱신 정책을 조사하고 지정한 링크만 갱신한다.
- **성공 기준:** 원본을150으로 바꾼 뒤 실제 엔진에서 target 값150을 확인한다.
- **실패·경계 실험:** 원본 파일이 없으면 이전 캐시값을 최신값으로 보고하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 L10만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
