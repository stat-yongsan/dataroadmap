#### N05 · HTML 결과 화면 만들기

**환경: L — 로컬 자료 처리**

- **입력 예제:** 부서별 집계A300,B200,C500을 둔다.
- **변환·출력 계약:** 표·합계·필터가 있는 로컬 HTML 결과 페이지를 만든다.
- **성공 기준:** 전체 합계1000, A만 선택 시300이며 페이지 새로고침 후 규칙이 일관된다.
- **실패·경계 실험:** 파일 내용의 HTML 태그를 데이터로 표시하고 코드로 실행하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 N05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
