#### M10 · 통합문서 파일 암호화

**환경: N — Excel 또는 지원 엔진 필요**

- **입력 예제:** 가상자료만 있는 예제 파일과 실습용 비밀번호를 로컬 입력으로 받는다.
- **변환·출력 계약:** 지원되는 Excel 저장 방식으로 파일 열기 암호를 지정한다.
- **성공 기준:** 암호 없이는 내용을 열 수 없고 올바른 암호로는 원자료를 읽을 수 있다.
- **실패·경계 실험:** 시트 보호만 적용한 파일을 암호화 완료라고 하지 않으며 비밀번호를 로그에 적지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 M10만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
