#### C10 · 안정적인 레코드 키 만들기

**환경: L — 로컬 자료 처리**

- **입력 예제:** 같은 학번이 학기 2026-1,2026-2에 각각 나타나는 2행을 둔다.
- **변환·출력 계약:** 학번+학기를 충돌 없는 직렬화 규칙으로 묶어 업무 키를 만든다.
- **성공 기준:** 키가 서로 다르고 행 순서를 바꿔도 같은 행의 키가 유지된다.
- **실패·경계 실험:** a+bc와 ab+c처럼 단순 연결로 충돌하는 입력을 별도 키로 처리한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 C10만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
