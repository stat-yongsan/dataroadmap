#### P09 · 실패 지점부터 재개

**환경: L — 로컬 자료 처리**

- **입력 예제:** A,B,C 세 단계 중 첫 실행에서C만 실패하도록 만든다.
- **변환·출력 계약:** 성공 단계의 산출물·입력 해시를 체크포인트에 남기고 재실행 때 검증한다.
- **성공 기준:** 재개 시A,B는 재사용하고C만 다시 실행한다.
- **실패·경계 실험:** A의 입력을 바꾸면 그에 의존하는B,C도 다시 실행한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P09만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
