### W15. API 자료를 DB에 누적

- 입력: 로컬 API의 1페이지에 id1 금액 100·id2 금액 200, 2페이지에 id3 금액 300. 저장 대상은 빈 SQLite DB다.
- 연결: A06 → D01 → F06 → O03 → P07 → N05.
- 계약: F06이 기존 DB 상태와 새 자료를 비교해 변경집합을 만들고, O03은 그 집합을 트랜잭션으로 반영한다.
- 정답: 첫 실행 3행·합계 600, 동일 배치 재실행 후에도 3행·600.
- 실패 실험: id2의 금액을 250으로 바꾸면 수정 1건 후 합계 650이고, 일부 쓰기 실패 시 배치 전체가 롤백된다.
