#### H03 · 반올림과 잔액 배분

**환경: L — 로컬 자료 처리**

- **입력 예제:** 100원을 동일 가중치의 A,B,C에 정수 원 단위로 배분한다.
- **변환·출력 계약:** 최대잔여법과 동률 시 키 오름차순 규칙으로 잔액을 배정한다.
- **성공 기준:** A34,B33,C33이고 합계가 정확히100이다.
- **실패·경계 실험:** 개별 반올림 때문에 합계99 또는102가 되는 구현은 실패다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 H03만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
