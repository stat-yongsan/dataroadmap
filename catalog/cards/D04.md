#### D04 · 허용값·범위 검사

**환경: L — 로컬 자료 처리**

- **입력 예제:** 점수 -1,0,100,101과 상태 완료·대기를 넣는다.
- **변환·출력 계약:** 점수 0~100 포함, 상태 완료·대기만 허용하는 규칙을 적용한다.
- **성공 기준:** 점수 오류는 -1,101의 2건이다.
- **실패·경계 실험:** 경계값 0과 100을 잘못 탈락시키지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 D04만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
