#### K06 · 상태 변화에만 알림 후보 생성

**환경: L — 로컬 자료 처리**

- **입력 예제:** 임계값100, 관측80,120,130,90,110의 시계열을 둔다.
- **변환·출력 계약:** 정상→초과 전환 때만 알림 이벤트를 만들고 현재 상태를 저장한다.
- **성공 기준:** 알림은120과110의 두 시점에서만 생성된다.
- **실패·경계 실험:** 동일 이벤트를 재처리해 알림 후보가 중복 생성되지 않게 한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 K06만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
