#### C02 · 문자열 공백·유니코드 정리

**환경: L — 로컬 자료 처리**

- **입력 예제:** 이름 값으로 앞뒤 공백, NBSP, 한글 조합형을 포함한 3개를 만든다.
- **변환·출력 계약:** 선택한 NFC 정규화와 공백 정책을 적용하고 원문을 유지한다.
- **성공 기준:** 논리적으로 같은 이름이 동일 표준 문자열이 된다.
- **실패·경계 실험:** 상품코드의 의미 있는 내부 공백이나 대소문자를 설정 없이 없애지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 C02만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
