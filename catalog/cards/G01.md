#### G01 · 가로 열을 세로 행으로 변환

**환경: L — 로컬 자료 처리**

- **입력 예제:** 부서A의 1월100·2월200, 부서B의 1월300·2월400을 둔다.
- **변환·출력 계약:** 월별 열을 부서·월·금액의 긴 표로 바꾼다.
- **성공 기준:** 4행, 합계1000이며 각 부서·월 조합이 유일하다.
- **실패·경계 실험:** 비고 열까지 월 데이터로 녹이지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 G01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
