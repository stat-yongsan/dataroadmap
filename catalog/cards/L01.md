#### L01 · 참조가 맞는 수식 작성

**환경: L — 로컬 자료 처리**

- **입력 예제:** B2=2,C2=3000,B3=3,C3=2000,F1=0.1인 통합문서를 만든다.
- **변환·출력 계약:** D열에는 B행*C행, E열에는 D행*$F$1 수식을 작성한다.
- **성공 기준:** D2=B2*C2, D3=B3*C3, E3=D3*$F$1이며 기대 값6000·600이다.
- **실패·경계 실험:** 수식을 쓴 것과 계산한 것을 구분한다. 이 실습의 자동 검증은 수식 문자열·참조 구조다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 L01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
