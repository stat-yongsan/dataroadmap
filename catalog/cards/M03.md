#### M03 · 입력 유효성·드롭다운

**환경: L — 로컬 자료 처리**

- **입력 예제:** 상태 허용값 대기·진행·완료를 기준 영역에 둔다.
- **변환·출력 계약:** 대상 열에 드롭다운·오류 메시지·빈칸 허용 정책을 설정한다.
- **성공 기준:** 정상3개 값이 선택 가능하고 임의값은 지정한 오류 방식으로 처리된다.
- **실패·경계 실험:** 붙여넣기 등으로 검사가 우회될 수 있어 D04 후속 검사를 함께 안내한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 M03만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
