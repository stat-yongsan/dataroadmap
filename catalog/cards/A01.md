#### A01 · 대상 파일 목록 만들기

**환경: L — 로컬 자료 처리**

- **입력 예제:** inbox에 report_01.xlsx, report_02.xlsx, ~$report_02.xlsx, readme.txt를 둔다.
- **변환·출력 계약:** 확장자·이름 규칙으로 처리 대상을 선택하고 상대경로·크기·SHA256을 manifest로 남긴다.
- **성공 기준:** 정상 xlsx 2개만 선택하며 Excel 임시 잠금 파일과 txt는 제외한다.
- **실패·경계 실험:** 같은 이름의 파일을 하위 폴더에 추가해도 서로 다른 경로로 식별한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 A01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
