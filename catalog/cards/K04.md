#### K04 · 일정·자원 배정

**환경: L — 로컬 자료 처리**

- **입력 예제:** 회의A는9~10시, B는10~11시, C는9:30~10:30이며 방2개를 둔다.
- **변환·출력 계약:** 시간 구간은 시작 포함·종료 제외로 보고 같은 방에 겹침 없이 배정한다.
- **성공 기준:** A와B는 같은 방 사용 가능, C는 다른 방이며 충돌0이다.
- **실패·경계 실험:** 방1개로 바꾸면 모든 회의를 배정할 수 없음을 보고한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 K04만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
