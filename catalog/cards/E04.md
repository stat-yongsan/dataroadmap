#### E04 · 정책에 따른 중복 해소

**환경: L — 로컬 자료 처리**

- **입력 예제:** 동일 id의 수정시각 09:00 금액100, 10:00 금액200과 다른 id 1행을 둔다.
- **변환·출력 계약:** 키별 최신 수정행을 남기고 제거된 행·선택 근거를 기록한다.
- **성공 기준:** 2행이 남고 중복 id의 금액은 200이다.
- **실패·경계 실험:** 최신 시각이 같은데 금액이 다르면 검토 대상으로 보낸다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 E04만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
