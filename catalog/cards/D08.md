#### D08 · 수식 오류·패턴 검사

**환경: L — 로컬 자료 처리**

- **입력 예제:** C2=B2*2, C3=#REF!를 참조한 수식, C4=999 고정값을 넣는다.
- **변환·출력 계약:** 수식 열의 오류 토큰과 기대 참조 패턴 이탈을 조사한다.
- **성공 기준:** 깨진 참조와 수식 대신 입력된 고정값을 각각 지적한다.
- **실패·경계 실험:** 계산 엔진이 없으면 실행 결과 오류까지 검증했다고 쓰지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 D08만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
