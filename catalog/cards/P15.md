#### P15 · 큰 자료를 나누어 처리

**환경: L — 로컬 자료 처리**

- **입력 예제:** 금액1이10000행인 CSV를 생성하고 chunk_size=777로 둔다.
- **변환·출력 계약:** 모든 행을 한꺼번에 올리지 않고 부분 집계 후 병합한다.
- **성공 기준:** 건수10000·합계10000이며 작은 전체읽기 기준 결과와 일치한다.
- **실패·경계 실험:** 청크마다 중복 제거·평균을 별개 적용해 전체 결과가 달라지는 오류를 검출한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P15만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
