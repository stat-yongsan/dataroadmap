#### P03 · 조건 분기·합류

**환경: L — 로컬 자료 처리**

- **입력 예제:** 오류건수가0인 입력과2인 입력을 준비한다.
- **변환·출력 계약:** 0이면 보고서 경로, 1이상이면 검토 경로로 보내고 허용된 경로만 합류시킨다.
- **성공 기준:** 각 입력에서 맞는 경로만 실행되며 미실행 경로는 skipped로 구분된다.
- **실패·경계 실험:** 검토 필요 자료가 검토 없이 보고서 확정 단계로 넘어가지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P03만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
