#### D07 · 독립 합계와 대조

**환경: L — 로컬 자료 처리**

- **입력 예제:** 상세 100,200과 별도 통제 합계 300을 준비한다.
- **변환·출력 계약:** 같은 기간·단위·모집단의 독립 통제값과 계산 합계를 비교한다.
- **성공 기준:** 차이 0이면 통과, 통제 합계 310이면 차이 -10으로 실패다.
- **실패·경계 실험:** 계산한 합계를 그대로 복사해 정답으로 삼지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 D07만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
