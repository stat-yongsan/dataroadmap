#### K08 · 저장한 모델로 추론

**환경: L — 로컬 자료 처리**

- **입력 예제:** 절편1·기울기2·특징명x인 모델 fixture와 x=4,5 입력을 둔다.
- **변환·출력 계약:** 모델 버전과 특징 규격을 검사한 뒤 재학습 없이 예측한다.
- **성공 기준:** 예측9,11이고 사용 모델 버전이 기록된다.
- **실패·경계 실험:** 특징 이름·단위가 달라지면 예측을 중단한다. 모르는 모델 파일을 임의 역직렬화하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 K08만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
