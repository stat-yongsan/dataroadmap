#### Q04 · 숫자 근거가 있는 요약

**환경: AI — 모델 처리 · mock과 실제 모델을 구분**

- **입력 예제:** 실적표에전월100·당월120과 계산된 증감률20%를 둔다.
- **변환·출력 계약:** 제공된 사실만 사용해 짧은 설명과 근거 셀·행키를 생성한다.
- **성공 기준:** 요약에120과20%가 정확하고 원인에 대한 새 사실은 없다.
- **실패·경계 실험:** 매출 증가 이유처럼 입력에 없는 인과 설명을 만들면 검증이 실패한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 Q04만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
