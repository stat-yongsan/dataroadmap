#### J01 · 시간 단위 재집계

**환경: L — 로컬 자료 처리**

- **입력 예제:** 9월1일 매출100·잔액1000, 9월2일 매출200·잔액1100을 둔다.
- **변환·출력 계약:** 흐름인 매출은 합, 잔액은 마지막 관측값으로 월 단위 집계한다.
- **성공 기준:** 9월 매출300, 말일 관측 잔액1100이다.
- **실패·경계 실험:** 잔액을2100으로 합산하지 않는다. 실제 월말 자료가 없으면 마지막 관측일을 표시한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 J01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
