#### A06 · 페이지가 있는 API 읽기

**환경: X — 외부 연결형 · 첫 실습은 로컬 mock**

- **입력 예제:** 로컬 HTTP 서버가 page1에 id 1,2와 next URL, page2에 id 3과 next=null을 반환하게 한다.
- **변환·출력 계약:** 다음 페이지가 끝날 때까지 조회하고 원응답과 수집 시각을 남긴다.
- **성공 기준:** 결과 id가 1,2,3이며 HTTP 요청은 2회다.
- **실패·경계 실험:** next가 자기 자신을 가리키면 무한 조회하지 않고 순환 오류를 기록한다.
