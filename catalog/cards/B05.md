#### B05 · 한 시트의 여러 표 나누기

**환경: L — 로컬 자료 처리**

- **입력 예제:** 한 시트의 A1:B4와 E1:F3에 서로 다른 표를 배치한다.
- **변환·출력 계약:** 지정 범위 또는 경계 규칙으로 독립 표를 추출해 각각 스키마를 붙인다.
- **성공 기준:** 데이터 행수가 각각 3행,2행이다.
- **실패·경계 실험:** 표 안의 빈칸 하나를 표 끝으로 오판하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 B05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
