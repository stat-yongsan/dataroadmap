#### D01 · 스키마·자료형 검사

**환경: L — 로컬 자료 처리**

- **입력 예제:** 필수 열 id:string, amount:decimal 규격과 amount 대신 amt인 입력을 준비한다.
- **변환·출력 계약:** 열 존재·타입·허용 추가 열 정책을 검사해 파일 수준 결과를 만든다.
- **성공 기준:** 정상 입력은 통과하고 amt 입력은 missing_column 오류다.
- **실패·경계 실험:** 선택 열만 빠진 경우는 필수 열 누락과 구분한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 D01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
