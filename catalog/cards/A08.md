#### A08 · HTML 표 추출하기

**환경: L — 로컬 자료 처리**

- **입력 예제:** 로컬 page.html에 안내 표 1개와 id=orders인 주문 표 1개를 만든다. 주문은 2행이다.
- **변환·출력 계약:** 표 식별자와 열 이름을 사용해 원하는 표만 추출한다.
- **성공 기준:** 주문 데이터 2행이며 안내 표의 행은 섞이지 않는다.
- **실패·경계 실험:** 대상 id가 없거나 동일 후보가 여럿이면 추측 대신 오류를 반환한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 A08만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
