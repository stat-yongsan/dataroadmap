#### M07 · 입력 셀과 수식 셀 보호

**환경: L — 로컬 자료 처리**

- **입력 예제:** 입력B2와 계산C2=B2*2를 가진 시트를 둔다.
- **변환·출력 계약:** 입력 셀만 잠금 해제하고 시트 보호를 설정한다.
- **성공 기준:** Excel에서B2는 편집 가능하고C2의 직접 수정은 제한된다.
- **실패·경계 실험:** 시트 보호를 파일 암호화나 개인정보 보안으로 설명하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 M07만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
