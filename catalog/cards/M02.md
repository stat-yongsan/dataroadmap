#### M02 · 조건부 서식 규칙

**환경: L — 로컬 자료 처리**

- **입력 예제:** 실적80,100,120과 목표100을 둔다.
- **변환·출력 계약:** 실적<목표인 셀만 강조하는 동적 조건부 서식을 만든다.
- **성공 기준:** 80만 강조되며 Excel에서80→110 변경 시 강조가 해제된다.
- **실패·경계 실험:** 셀 배경색을 고정하는 방식은 동적 규칙 실습의 대체가 아니다. 엔진 반응 확인 여부를 기록한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 M02만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
