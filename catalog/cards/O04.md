#### O04 · 외부 API에 결과 등록

**환경: X — 외부 연결형 · 첫 실습은 로컬 mock**

- **입력 예제:** 로컬 HTTP mock에 request_id=R001,amount=100 등록 요청을 만든다.
- **변환·출력 계약:** 명시한 API 스키마와 idempotency key로 등록하고 응답 식별자를 저장한다.
- **성공 기준:** mock에 같은 요청을2번 보내도 등록은1건이다.
- **실패·경계 실험:** 대상 API가 멱등 키를 지원하지 않으면 자동 재시도 안전성을 보장한다고 하지 않는다.
