#### B02 · 여러 줄 머리글 평탄화

**환경: L — 로컬 자료 처리**

- **입력 예제:** 2줄 머리글을 매출/매출 및 1월/2월로 만들고 A부서 100/200을 둔다.
- **변환·출력 계약:** 상하 머리글을 조합해 중복 없는 열 이름과 원래 계층 정보를 만든다.
- **성공 기준:** 열 이름은 매출_1월, 매출_2월이며 값은 100,200이다.
- **실패·경계 실험:** 조합 후 열 이름이 중복되면 충돌을 보고하고 원본 위치를 보존한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 B02만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
