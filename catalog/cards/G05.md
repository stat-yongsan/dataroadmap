#### G05 · 모든 조합의 기준 격자 만들기

**환경: L — 로컬 자료 처리**

- **입력 예제:** 부서 A,B와 월 1,2,3을 둔다.
- **변환·출력 계약:** 각 집합의 Cartesian product로 기대 조합 표를 만든다.
- **성공 기준:** 6행이며 모든 부서·월 조합이 한 번씩 나온다.
- **실패·경계 실험:** 예상 조합수가 설정 한도를 넘으면 메모리를 소진하기 전에 중단한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 G05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
