#### Q05 · 자연어 요청을 실행계획으로 바꾸기

**환경: AI — 모델 처리 · mock과 실제 모델을 구분**

- **입력 예제:** 요청 완료 신청만 부서별로 합계 내고 그래프로 보여줘와 허용 step 목록을 둔다.
- **변환·출력 계약:** 열 이름·규칙·단계 id로 이루어진 제한된 JSON 계획을 만든다.
- **성공 기준:** E01→I01→N02와 상태=완료 조건이 포함되고 미정의 단계가 없다.
- **실패·경계 실험:** 모델이 낸 임의 코드를 바로 실행하지 않고 스키마·입출력 계약 검사 뒤 실행한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 Q05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
