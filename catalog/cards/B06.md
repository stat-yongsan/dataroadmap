#### B06 · 양식 셀에서 레코드 추출

**환경: L — 로컬 자료 처리**

- **입력 예제:** 신청서 C3=R001, C5=엑셀교육, F8=50000인 양식을 만든다.
- **변환·출력 계약:** 셀 주소·필드명 매핑으로 1장의 양식을 레코드 1개로 바꾼다.
- **성공 기준:** request_id=R001, program=엑셀교육, amount=50000이다.
- **실패·경계 실험:** 필수 셀이 비어 있거나 양식 버전이 다르면 해당 필드를 누락으로 기록한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 B06만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
