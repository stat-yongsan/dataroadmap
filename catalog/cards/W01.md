### W01. 부서별 지출 보고서

- 입력: F01의3개 CSV, 독립 통제 합계100000, 가상 보고서 양식.
- 연결: A01 → A03 → C01 → C03 → F01 → D03 → I01 → D07 → M04. I01에서 N02 → N03으로 차트 출력도 분기한다.
- 계약: 원본 여러 표 → 거래6행 → 부서3행 → 보고서와JPG. D07의 통제 합계는 계산 결과와 별도로 제공한다.
- 정답: 교과30000,비교과20000,지원50000,전체100000. 그래프는 이3개 값을 사용한다.
- 실패 실험: 파일 하나의 금액을 수정해 통제 합계와 불일치시키면 최종 발행 상태는 failed 또는 needs_review다.
