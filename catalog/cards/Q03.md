#### Q03 · 의미로 관련 행 찾기

**환경: AI — 모델 처리 · mock과 실제 모델을 구분**

- **입력 예제:** 규정 행에 수강 철회 절차·장학금 지급과 질의 강의를 취소하려면을 둔다.
- **변환·출력 계약:** 사용 가능한 임베딩 또는 모델로 의미 후보를 검색하고 원문 행키를 반환한다.
- **성공 기준:** 정답 fixture인 수강 철회 절차가 상위 결과에 있는지 평가한다.
- **실패·경계 실험:** 검색 점수를 정답 확률로 부르지 않고 모델이 없으면 mock으로 명시한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 Q03만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
