#### F01 · 같은 구조의 표 세로 합치기

**환경: L — 로컬 자료 처리**

- **입력 예제:** 교과.csv 금액10000·20000, 비교과.csv 15000·5000, 지원.csv 25000·25000을 준비한다. 각 파일은 2행이다.
- **변환·출력 계약:** 동일 스키마 표를 이어 붙이고 source_file·source_row를 추가한다.
- **성공 기준:** 총 6행, 총액100000, 부서별 교과30000·비교과20000·지원50000이다.
- **실패·경계 실험:** 열 하나를 누락시키면 해당 파일을 오류로 표시하며 성공 파일만으로 전체 성공을 선언하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 F01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
