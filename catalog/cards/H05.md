#### H05 · 그룹 내 순위 계산

**환경: L — 로컬 자료 처리**

- **입력 예제:** A집단 점수100,90,90,80과 B집단 점수70,60을 둔다.
- **변환·출력 계약:** 집단별 competition rank를 적용한다.
- **성공 기준:** A 순위1,2,2,4와 B 순위1,2다.
- **실패·경계 실험:** dense rank로 바꾸면 A가1,2,2,3임을 구분하고 정책을 저장한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 H05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
