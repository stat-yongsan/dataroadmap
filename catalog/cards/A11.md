#### A11 · 스캔 표 OCR 추출

**환경: V — 로컬 OCR 엔진 필요**

- **입력 예제:** 선명한 표 이미지에 코드 001,002와 금액 100,200을 넣고 흐릿한 변형도 만든다.
- **변환·출력 계약:** 사용 가능한 로컬 OCR로 텍스트·위치·신뢰도 정보를 추출하고 정답 fixture와 대조한다.
- **성공 기준:** 선명한 표에서 기대 2행을 비교 보고한다. 불일치가 있으면 검토 상태로 남긴다.
- **실패·경계 실험:** 0/O 또는 1/I 오인식 사례를 넣어 자동 확정하지 않는지 확인한다. OCR 미설치는 BLOCKED다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 A11만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
