#### P10 · 동시 실행 충돌 제어

**환경: L — 로컬 자료 처리**

- **입력 예제:** 두 프로세스가 같은 final.csv를 갱신하려는 실험을 만든다.
- **변환·출력 계약:** 프로세스 간 잠금 또는 조건부 버전 검사를 사용해 쓰기를 직렬화한다.
- **성공 기준:** 두 요청 중 하나가 기다리거나 명시적으로 충돌하며 최종 파일이 섞이지 않는다.
- **실패·경계 실험:** 강제 종료 뒤 잠금 회수 정책을 정하고 단순히 파일이 있으면 영원히 잠겼다고 보지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P10만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
