#### M01 · 일관된 서식 적용

**환경: L — 로컬 자료 처리**

- **입력 예제:** id=0001, 금액12345, 비율0.25, 날짜2026-09-01인 표를 둔다.
- **변환·출력 계약:** 열 의미별 숫자·날짜 표시와 제목·본문 스타일을 일괄 적용한다.
- **성공 기준:** 값의 타입은 유지되고 금액12,345·비율25.0%로 표시되며 한글과 열 폭이 읽힌다.
- **실패·경계 실험:** 문자열로 예쁘게 바꿔 계산을 못 하게 하거나 열 폭 때문에 잘리게 하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 M01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
