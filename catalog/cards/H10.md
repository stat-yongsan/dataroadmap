#### H10 · 포함 금액을 구성요소로 분해

**환경: L — 로컬 자료 처리**

- **입력 예제:** 합계110과 예제용 비율10%를 둔다.
- **변환·출력 계약:** 합계=기준금액×(1+비율) 규칙으로 기준금액과 추가금액을 분리한다.
- **성공 기준:** 기준100, 추가10이며 다시 합치면110이다.
- **실패·경계 실험:** 합계에10%를 곱해 추가금액11로 잘못 계산하지 않는다. 법정 세율로 가정하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 H10만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
