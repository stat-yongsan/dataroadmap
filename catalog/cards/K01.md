#### K01 · 가정값 조합 비교

**환경: L — 로컬 자료 처리**

- **입력 예제:** 매출=가격×수량, 가격=[100,120], 수량=[10,20]을 둔다.
- **변환·출력 계약:** 가정 격자별 같은 계산 함수를 실행하고 입력과 결과를 묶는다.
- **성공 기준:** 4개 결과1000,2000,1200,2400이 생성된다.
- **실패·경계 실험:** 기존 사례 결과를 덮어쓰거나 사례마다 다른 계산식을 쓰지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 K01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
