#### Q01 · 자유서술의 범주 분류

**환경: AI — 모델 처리 · mock과 실제 모델을 구분**

- **입력 예제:** 문장 엑셀 함수가 어려워요·강의실이 추워요·안녕하세요와 라벨 학습·시설·기타를 둔다.
- **변환·출력 계약:** 정해진 라벨과 보류값만 반환하고 원문 근거를 보존한다.
- **성공 기준:** fixture 기준 학습·시설·기타로 비교하며 다른 결과는 평가에 그대로 남긴다.
- **실패·경계 실험:** 모호한 문장을 억지로 확정하지 않는다. demo의 규칙 기반 대체는 AI 실행으로 표시하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 Q01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
