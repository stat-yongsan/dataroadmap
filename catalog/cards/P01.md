#### P01 · 설정을 코드 밖으로 분리

**환경: L — 로컬 자료 처리**

- **입력 예제:** 동일 표에 설정파일A는최소금액100, 설정B는200을 둔다.
- **변환·출력 계약:** 입력·출력·기간·업무 규칙을 config에서 읽고 유효성을 검사한다.
- **성공 기준:** 코드를 바꾸지 않고 설정에 따라 다른 행이 선택되며 설정 해시가 기록된다.
- **실패·경계 실험:** 알 수 없는 설정키나 잘못된 자료형을 조용히 무시하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
