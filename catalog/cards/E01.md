#### E01 · 조건으로 행 선택

**환경: L — 로컬 자료 처리**

- **입력 예제:** 상태 완료 금액 100, 대기 200, 완료 300의 3행을 둔다.
- **변환·출력 계약:** 상태=완료 AND 금액≥200인 행을 선택한다.
- **성공 기준:** 선택 1행, 금액 300이다.
- **실패·경계 실험:** 상태 null의 포함 여부를 명시하고 임의로 완료로 처리하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 E01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
