#### L05 · Excel Table 생성·범위 확장

**환경: L — 로컬 자료 처리**

- **입력 예제:** A1:B3에 id·amount와2행을 넣고 Sales라는 Table을 만든다.
- **변환·출력 계약:** 새 데이터1행을 추가할 때 표 참조 범위와 표 머리글을 갱신한다.
- **성공 기준:** 표 범위는A1:B4이며 추가 행도 Table 안에 있다.
- **실패·경계 실험:** 셀에 값만 넣고 표 범위를 이전 크기에 두지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 L05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
