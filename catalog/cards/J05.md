#### J05 · 기준 예측 만들기

**환경: L — 로컬 자료 처리**

- **입력 예제:** 월별 관측100,110,120,130을 둔다.
- **변환·출력 계약:** 학습 종료시점까지의 마지막 값을 다음 기간 예측으로 쓰는 naive 모델을 만든다.
- **성공 기준:** 다음1기간 예측130이며 방법과 학습 종료시점이 기록된다.
- **실패·경계 실험:** 예측을 확정 실적으로 기록하지 않는다. 복잡한 모델은 이 기준 모델과 비교한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 J05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
