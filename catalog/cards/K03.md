#### K03 · 제약조건 안에서 최적화

**환경: L — 로컬 자료 처리**

- **입력 예제:** 정수 x,y≥0, 2x+y≤4, 목적3x+2y 최대화를 둔다.
- **변환·출력 계약:** 의사결정변수·제약·목표를 명시하고 작은 예제는 전수조사 또는 해법기로 푼다.
- **성공 기준:** 최적 x=0,y=4, 목적값8이다.
- **실패·경계 실험:** 실행 불가능한 제약을 추가하면 feasible 결과를 꾸며내지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 K03만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
