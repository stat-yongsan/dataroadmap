#### N04 · 통합문서 PDF 출력

**환경: N — Excel 또는 지원 엔진 필요**

- **입력 예제:** 인쇄영역을 설정한1페이지 예제 통합문서를 둔다.
- **변환·출력 계약:** 실제 지원 렌더러로 PDF를 만들고 페이지·텍스트·잘림을 점검한다.
- **성공 기준:** 기대1페이지이며 제목·합계가 포함된다.
- **실패·경계 실험:** 추가 빈페이지나 다른 렌더러의 레이아웃 차이를 확인 없이 통과시키지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 N04만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
