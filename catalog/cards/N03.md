#### N03 · 차트·표를 JPG로 내보내기

**환경: L — 로컬 자료 처리**

- **입력 예제:** N02와 같은 차트 또는 로컬 HTML 표 fixture를 만들고1600×900 출력을 지정한다.
- **변환·출력 계약:** 여백·배경·해상도를 고정해 실제 JPEG 바이트로 저장한다.
- **성공 기준:** 파일 형식JPEG, 픽셀1600×900이며 한글·수치가 모두 보인다.
- **실패·경계 실험:** 확장자만 jpg인 PNG를 만들지 않고 투명 배경은 지정 배경색으로 합성한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 N03만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
