#### C09 · 결측값 처리 정책

**환경: L — 로컬 자료 처리**

- **입력 예제:** status=[완료,빈칸,미상], amount=[0,빈칸,100]을 준비한다.
- **변환·출력 계약:** 열별로 보존·제외·고정값 대체 중 지정한 정책만 적용하고 처리 사유를 기록한다.
- **성공 기준:** status 빈칸만 미입력으로 채우고 금액 빈칸은 null, 실제 0은 0으로 남긴다.
- **실패·경계 실험:** 금액을 평균이나 0으로 임의 대체하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 C09만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
