#### M08 · 기존 매크로 실행·보존

**환경: N — Excel 또는 지원 엔진 필요**

- **입력 예제:** 직접 만든 예제 매크로가 Output!A1에완료를 쓰는 .xlsm을 둔다.
- **변환·출력 계약:** 예제 매크로만 실행하고 VBA 포함 파일 형식으로 사본을 저장한다.
- **성공 기준:** A1=완료이고 재개방 후 매크로가 남아 있다.
- **실패·경계 실험:** xlsx로 저장해 VBA를 잃거나 출처 불명 매크로를 자동 실행하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 M08만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
