#### K05 · 불확실성 시뮬레이션

**환경: L — 로컬 자료 처리**

- **입력 예제:** 수요가100 또는200으로 각각0.5 확률, 단가10인 모형을 둔다.
- **변환·출력 계약:** 고정 seed의 반복 추출로 수익 분포를 계산한다.
- **성공 기준:** 가능 수익은1000·2000뿐이며 충분한 반복에서 평균이 이론값1500에 근접한다.
- **실패·경계 실험:** 반복10000일 때 평균 오차허용50을 사전 지정하고 미래 실적 보장으로 설명하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 K05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
