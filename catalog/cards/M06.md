#### M06 · 인쇄 영역·페이지 설정

**환경: L — 로컬 자료 처리**

- **입력 예제:** 제목1행과20개 자료행, 합계행이 있는 표를 둔다.
- **변환·출력 계약:** 인쇄영역·용지·방향·반복 제목·배율을 설정한다.
- **성공 기준:** 인쇄영역에 제목·20행·합계가 모두 있고 미리보기 확인 항목이 제공된다.
- **실패·경계 실험:** 한 페이지에 강제로 맞추며 글자가 읽을 수 없게 되면 행 방향 페이지 분할을 허용한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 M06만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
