#### P14 · 사람의 판단을 이어받기

**환경: L — 로컬 자료 처리**

- **입력 예제:** 유사매칭 후보R001이 검토 대기이며 후보A,B가 있는 자료를 둔다.
- **변환·출력 계약:** 실행id·입력해시·대상키에 연결된 승인·수정·반려 결정을 저장하고 파이프라인을 재개한다.
- **성공 기준:** 해당 실행의A 승인 후에만 확정 매칭A가 다음 단계로 넘어간다.
- **실패·경계 실험:** 입력이 바뀌면 이전 승인을 재사용하지 않는다. 실습은 로컬 결정파일로 진행한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P14만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
