#### M09 · 버튼·입력폼·이벤트 연결

**환경: N — Excel 또는 지원 엔진 필요**

- **입력 예제:** 숫자 입력셀B2, 결과셀C2와 계산 버튼을 둔다.
- **변환·출력 계약:** 사용자가 버튼을 누르면 지정 동작으로 C2=B2*2를 갱신한다.
- **성공 기준:** B2=7에서 클릭하면C2=14가 되고 실행 시각이 보인다.
- **실패·경계 실험:** 이벤트 재진입·무한 호출을 막고 Office Scripts의 실행 방식과 VBA 이벤트를 혼동하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 M09만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
