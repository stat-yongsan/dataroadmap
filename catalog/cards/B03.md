#### B03 · 병합셀의 의미 복원

**환경: L — 로컬 자료 처리**

- **입력 예제:** A2:A4를 교과로 병합하고 옆 열에 학생 3명을 넣는다.
- **변환·출력 계약:** 지정한 분류 열의 병합 범위에만 대표값을 전파해 행 단위 표를 만든다.
- **성공 기준:** 학생 3행 모두 부서=교과다.
- **실패·경계 실험:** 금액 열의 일반 빈칸까지 앞 값으로 채우지 않는지 확인한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 B03만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
