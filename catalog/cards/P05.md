#### P05 · 예약 시각에 실행

**환경: L — 로컬 자료 처리**

- **입력 예제:** Asia/Seoul 매일09:00 규칙과2026-09-23 08:59의 가상 시각을 둔다.
- **변환·출력 계약:** 먼저 fake clock으로 실행시각을 계산하고 선택한 OS용 스케줄 등록·해제 명령을 생성한다.
- **성공 기준:** 가상 시각09:00에실행1회이며 중복 트리거는 같은 실행키로 묶인다.
- **실패·경계 실험:** 실제 OS 예약 등록은 이 실습에서 사용자가 선택할 때만 한다. PC가 꺼진 경우의 누락 정책을 기록한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
