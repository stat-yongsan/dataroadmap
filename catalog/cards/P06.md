#### P06 · 새 파일 도착 감지

**환경: L — 로컬 자료 처리**

- **입력 예제:** 로컬 inbox에 .part로 쓰다가 .csv로 이름을 바꾸는 파일을 만든다.
- **변환·출력 계약:** 완성된 파일만 감지하고 안정화 조건을 충족하면 이벤트를 만든다.
- **성공 기준:** 쓰기 중에는0회, 완성 후1회 처리된다.
- **실패·경계 실험:** 같은 파일 변경 알림이 여러 번 와도 P07과 결합해 중복 처리를 막는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P06만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
