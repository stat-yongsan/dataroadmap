#### E02 · 복수 기준 안정 정렬

**환경: L — 로컬 자료 처리**

- **입력 예제:** A:90점, B:90점, C:80점에 접수순번 2,1,3을 둔다.
- **변환·출력 계약:** 점수 내림차순, 접수순번 오름차순으로 정렬한다.
- **성공 기준:** 순서는 B,A,C다.
- **실패·경계 실험:** 동점 처리와 null 위치를 지정해 재실행마다 순서가 바뀌지 않게 한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 E02만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
