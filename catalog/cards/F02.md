#### F02 · 키로 표 연결·기준값 조회

**환경: L — 로컬 자료 처리**

- **입력 예제:** 주문 (S01,100),(S01,200),(S02,300)과 학생 기준표 S01=가람,S02=나래를 둔다.
- **변환·출력 계약:** 키로 many-to-one left join을 수행하고 연결 관계를 검증한다.
- **성공 기준:** 주문 3행과 합계600을 유지하며 이름이 채워진다.
- **실패·경계 실험:** 기준표 S01을 중복시키면 행이 불어나기 전에 오류를 낸다. 빈 키끼리는 매칭하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 F02만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
