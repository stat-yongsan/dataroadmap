#### P12 · 완성 결과의 원자적 공개·복원

**환경: L — 로컬 자료 처리**

- **입력 예제:** 기존v1 결과가 있고 새v2를 임시경로에 쓰는 중 오류를 넣는다.
- **변환·출력 계약:** 검증된 결과만 같은 파일시스템의 원자적 교체 또는 버전 포인터로 공개한다.
- **성공 기준:** 실패 시사용자는v1만 보고, 성공 시온전한v2만 보며 v1 복원 경로가 있다.
- **실패·경계 실험:** 여러 파일 묶음은 단일 파일 rename만으로 전체 원자성을 보장한다고 하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P12만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
