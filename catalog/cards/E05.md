#### E05 · 행 단위 계산 열 추가

**환경: L — 로컬 자료 처리**

- **입력 예제:** 수량·단가가 (2,3000),(3,2000)인 두 행을 둔다.
- **변환·출력 계약:** 금액=수량×단가라는 순수 계산으로 새 열을 만든다.
- **성공 기준:** 금액은 6000,6000이며 합계는 12000이다.
- **실패·경계 실험:** 음수 수량이나 누락값의 허용 여부를 설정하고 문자열을 코드로 eval하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 E05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
