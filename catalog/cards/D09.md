#### D09 · 이상치 후보 표시

**환경: L — 로컬 자료 처리**

- **입력 예제:** 값 10,11,12,13,100을 둔다.
- **변환·출력 계약:** 선형 보간 사분위수의 1.5×IQR 규칙으로 후보를 표시하고 기준을 기록한다.
- **성공 기준:** Q1=11, Q3=13, 상한=16이며 100만 후보가 된다.
- **실패·경계 실험:** 후보를 오류라고 단정하거나 자동 삭제하지 않는다. 표본이 적으면 그 사실을 표시한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 D09만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
