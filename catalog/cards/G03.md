#### G03 · 한 셀의 목록을 여러 행으로 펼치기

**환경: L — 로컬 자료 처리**

- **입력 예제:** R001의 프로그램=[엑셀,AI], R002의 프로그램=[글쓰기]를 둔다.
- **변환·출력 계약:** 목록 원소마다 행을 만들고 원본 키·원소 순번을 보존한다.
- **성공 기준:** 3행이며 R001은 2행이다.
- **실패·경계 실험:** 목록이 빈 경우 유지/제외 정책을 정한다. 금액이 함께 복제되면 중복 집계를 경고한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 G03만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
