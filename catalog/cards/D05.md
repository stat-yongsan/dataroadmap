#### D05 · 행 안의 업무 규칙 검사

**환경: L — 로컬 자료 처리**

- **입력 예제:** 신청 10·인증 8, 신청 5·인증 7, 시작일이 종료일보다 늦은 행을 둔다.
- **변환·출력 계약:** 인증≤신청, 시작≤종료처럼 필드 사이 제약을 판정한다.
- **성공 기준:** 뒤의 두 행만 규칙 위반이며 어떤 규칙인지 표시된다.
- **실패·경계 실험:** 신청수가 누락된 행을 정상으로 통과시키지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 D05만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
