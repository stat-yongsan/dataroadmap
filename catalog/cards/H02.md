#### H02 · 가중평균 계산

**환경: L — 로컬 자료 처리**

- **입력 예제:** 점수80·인원10과 점수100·인원30을 둔다.
- **변환·출력 계약:** 점수×인원 합을 인원 합으로 나눈다.
- **성공 기준:** 결과는 95이며 단순평균90과 구분된다.
- **실패·경계 실험:** 가중치 합0 또는 음수 가중치의 허용 정책을 명시한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 H02만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
