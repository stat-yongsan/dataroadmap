#### A10 · 텍스트 PDF의 표 추출

**환경: L — 로컬 자료 처리**

- **입력 예제:** 텍스트로 생성한 1페이지 PDF에 품목 A 100, B 200을 넣는다.
- **변환·출력 계약:** 페이지·표 위치를 근거로 셀 값을 추출한다. 스캔 PDF는 이 단계 대상에서 제외한다.
- **성공 기준:** 2행, 금액 합계 300이며 페이지 번호가 보존된다.
- **실패·경계 실험:** 행이 찢어지거나 머리글이 반복되는 변형은 경고 또는 검토 대상으로 분리한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 A10만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
