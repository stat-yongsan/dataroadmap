#### K02 · 목표값을 만드는 입력 찾기

**환경: L — 로컬 자료 처리**

- **입력 예제:** 매출=100×수량, 목표매출1000, 수량 범위0~20을 둔다.
- **변환·출력 계약:** 한 입력을 조정해 목표와 결과의 차이가 허용오차 이내가 되게 한다.
- **성공 기준:** 수량10이며 잔차0이다.
- **실패·경계 실험:** 목표3000은 범위 안에 해가 없다고 반환하고 마지막 시도값을 정답으로 쓰지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 K02만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
