#### D06 · 참조 무결성 검사

**환경: L — 로컬 자료 처리**

- **입력 예제:** 신청표 부서코드 D01,D99와 기준표 D01,D02를 준비한다.
- **변환·출력 계약:** 자식 키가 기준표에 존재하는지 확인하고 미등록 키 목록을 반환한다.
- **성공 기준:** D99 1건만 오류다.
- **실패·경계 실험:** 기준표에 D01이 중복되면 기준표 자체의 키 오류도 보고한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 D06만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
