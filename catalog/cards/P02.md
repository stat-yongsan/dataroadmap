#### P02 · 의존관계에 따라 단계 실행

**환경: L — 로컬 자료 처리**

- **입력 예제:** 가져오기→정리→집계와 정리→오류표의 분기 구조를 가진 작은 step fixture를 둔다.
- **변환·출력 계약:** 선행 단계 성공과 산출물 계약을 확인하고 DAG 순서대로 실행한다.
- **성공 기준:** 정리 완료 후 집계·오류표가 실행되며 존재하지 않는 선행 산출물은 읽지 않는다.
- **실패·경계 실험:** 순환 의존관계와 앞 단계 실패를 감지한다. 병렬 에이전트 없이 일반 코드로 구현해도 된다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P02만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
