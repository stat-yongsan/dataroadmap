#### C07 · 코드·명칭 사전 치환

**환경: L — 로컬 자료 처리**

- **입력 예제:** 부서 값 교혁·교육혁신센터·미등록을 넣고 앞의 두 값을 교육혁신지원센터로 매핑한다.
- **변환·출력 계약:** 명시적 사전으로 표준 명칭과 매핑 상태를 만든다.
- **성공 기준:** 정상 매핑 2건, 미등록 1건이다.
- **실패·경계 실험:** 사전에 없는 값을 비슷해 보인다는 이유로 자동 확정하지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 C07만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
