#### G07 · 빠진 기간·조합 보완

**환경: L — 로컬 자료 처리**

- **입력 예제:** A부서 1월100,3월300과 기대 월 1~3월을 둔다.
- **변환·출력 계약:** 기준 격자에 관측값을 연결하고 관측 누락 플래그를 만든다.
- **성공 기준:** 2월 행이 추가되고 금액은 null, missing_observation=true다.
- **실패·경계 실험:** 실제 관측된 0과 관측이 없는 null을 구분한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 G07만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
