#### P13 · 입력·로직 버전 변경 검증

**환경: L — 로컬 자료 처리**

- **입력 예제:** v1 규격은amount, v2는amount_krw로 열 이름이 바뀐 fixture를 둔다.
- **변환·출력 계약:** 버전별 명시적 변환과 고정 정답을 비교하여 호환·비호환 변경을 판정한다.
- **성공 기준:** 지원하는 v2는 같은 금액 결과를 만들고 알 수 없는 v3는 실패한다.
- **실패·경계 실험:** 출력에 맞춰 기대 정답을 자동 덮어쓰지 않는다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 P13만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
