#### C04 · 날짜·시각 표준화

**환경: L — 로컬 자료 처리**

- **입력 예제:** 2026-09-01, 2026/09/02, 2026-09-01T00:00:00Z를 넣는다.
- **변환·출력 계약:** 허용 형식과 Asia/Seoul 기준을 명시하여 날짜 또는 시간대 있는 ISO 시각으로 변환한다.
- **성공 기준:** UTC 시각은 2026-09-01T09:00:00+09:00이다.
- **실패·경계 실험:** 02/03/2026은 형식 지정 없이 해석하지 않는다. Excel 일련번호는 1900/1904 기준을 확인한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 C04만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
