#### B01 · 머리글 행 찾기

**환경: L — 로컬 자료 처리**

- **입력 예제:** 1행 제목, 2행 설명, 3행 id·amount, 4~6행 데이터인 시트를 만든다.
- **변환·출력 계약:** 필수 열 집합과 후보 점수로 머리글 행을 찾고 선택 근거를 남긴다.
- **성공 기준:** 머리글=3행, 데이터=3행이다.
- **실패·경계 실험:** 동일한 머리글 후보가 두 군데면 임의 선택하지 않고 범위 지정을 요구한다.

**Claude Code 실행 요청:** “공통 실습 계약을 적용해 B01만 구현하고 실행해줘. 위 입력과 정답을 먼저 만들고, 정상 실행과 실패 실험을 확인해줘.”
