#### A02 · 엑셀 범위를 표로 읽기

**환경: L — 로컬 자료 처리**

- **입력 예제:** Claude가 sample.xlsx의 Data!B3:D6에 머리글 id, qty, price와 데이터 3행을 만든다. id는 0001, 0002, 0003이다.
- **변환·출력 계약:** 시트·범위 또는 Excel Table 이름을 지정해 값과 원본 셀 위치를 읽는다.
- **성공 기준:** 데이터 3행·3열이며 id 0001의 앞자리 0이 유지된다.
- **실패·경계 실험:** 시트명이나 범위를 틀리면 빈 표로 성공 처리하지 않고 대상을 찾지 못했다고 알린다.
