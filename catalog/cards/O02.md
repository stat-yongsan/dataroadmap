#### O02 · 클라우드 파일 업로드

**환경: X — 외부 연결형 · 첫 실습은 로컬 mock**

- **입력 예제:** 로컬 mock 저장소와 보고서 v1·v2를 둔다.
- **변환·출력 계약:** 파일 식별자·버전 조건을 사용하여 생성 또는 지정 파일 교체 요청을 만든다.
- **성공 기준:** mock에서 같은 파일의 버전1→2이며 다른 파일을 만들거나 덮어쓰지 않는다.
- **실패·경계 실험:** 버전 충돌은 기록하고 기존 파일에 강제 덮어쓰기하지 않는다. live 완료와 mock 완료를 구분한다.
