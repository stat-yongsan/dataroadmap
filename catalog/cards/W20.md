### W20. Excel에서 새로고침되는 대시보드

- 입력: 로컬 CSV에 A100,A200,B300. 실제 Excel 환경을 사용한다.
- 연결: L08 → L05 → L07 → N01 → L11 → M06 → N04.
- 계약: Power Query 로드 표를 기준으로 실제 PivotTable·차트·필터를 연결한다. L05는 로드 표의 Table 범위 상태를 확인·관리한다.
- 정답: 초기 총 600, A50 추가 후 새로고침 총 650·A350·B300. A 필터를 선택하면 350만 보인다.
- 실패 실험: 새로고침 전 600을 최신 결과로 PDF 출력하지 않는다. Excel 엔진이 없으면 이 종합 실습은 BLOCKED다.

### 종합 프로젝트를 시작하는 복사 문장

```text
PIPELINES.md의 W02를 구현하고 싶다.
PROJECT_INDEX.md에서 필요한 번호를 확인하고 해당 프로젝트 명세만 읽어라.

먼저 입력1행의 의미와 각 연결선의 입출력 스키마를 PIPELINE_PLAN.md에 적어라.
기존에 구현된 조각은 재사용하고, 없는 조각은 W02에 필요한 범위만 구현하라.
모든 가상 입력을 자동 생성하고 파이프라인 전체를 실제 실행하라.
단계별 manifest, 중간 결과, 최종 결과와 고정 정답 검증을 남겨라.
단계 하나를 실패시키고 잘못된 결과가 최종 성공으로 공개되지 않는지도 확인하라.
구현 계획만 설명하고 멈추지 말고, 사용자 환경에서 가능한 실행까지 완료하라.
```

통합 MD만 사용한다면 위 문장의 PIPELINES.md를 이 파일의 8장으로, PROJECT_INDEX.md를 7장으로 바꿔서 요청하면 된다.
