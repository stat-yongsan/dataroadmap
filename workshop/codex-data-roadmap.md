# Codex와 데이터 활용 로드맵 실습

약 30분 동안 가상 CSV를 살펴보고, 목표에 맞는 계획을 세운 뒤 결과를 검증합니다. 이 실습에서는 실제 업무 파일을 사용하지 않습니다.

## 준비

Python 3.13, Node.js 22와 npm을 준비하고 저장소의 `run.bat`을 실행하세요. 앱 주소는 `http://127.0.0.1:8765`입니다. 자세한 설치는 [README](../README.md)를 참고하세요. Codex에게 이 저장소의 [data-roadmap Skill](../skills/data-roadmap/SKILL.md)을 읽고 도와달라고 요청할 수 있습니다.

## 0–5분: 작업의 범위 이해

화면 아래 카탈로그에서 17개 영역을 선택해 153개 작업 카드를 살펴봅니다. 카드는 가능한 작업의 목록이며, 이 프로토타입에서 실행할 수 있는 목표는 **그룹별 합계**와 **그룹별 건수** 두 가지입니다.

## 5–15분: 데이터에서 계획까지

1. **가상 예제 시작하기**를 누르고 1,000행의 열과 처음 5행을 확인합니다.
2. **그룹별 합계**를 선택하고 그룹 열은 `부서`, 금액 열은 `금액`인지 확인합니다.
3. **분석 경로 만들기**를 누르고 가능한 작업 순서를 확인합니다. 이 단계는 아직 결과 계산을 실행하지 않습니다.
4. 원하는 경로의 **결과 미리보기**를 눌러 사본에서 실행한 부서별 결과와 검증 상태를 확인합니다. 기대 합계는 **148,982,900**입니다. N02가 포함된 경로는 차트도 보여 줍니다.

Codex에게 “이 파일의 열을 살펴보고 그룹별 합계 계획을 만들어 줘. 실제 실행 결과와 아직 실행하지 않은 계획을 구분해 줘”라고 요청해 보세요.

## 15–25분: 비교하고 확인하기

1. **그룹별 건수**를 선택해 새 계획을 만들고 경로를 미리봅니다. 그룹별 건수의 합이 **1,000건**인지 확인합니다.
2. 앱의 **GPT-6 Luna vs Jev 1.13.0 결정 속도 비교**를 열어 보낼 열 이름·행 수·목표와 선택지를 살펴봅니다. 원본 행은 전송하지 않습니다.
3. 선택 활동: OpenAI와 Jev API 키가 준비돼 있고 외부 전송과 비용에 동의하는 경우에만 각 1회 비교합니다. API 시간에는 네트워크와 응답 처리가 포함되며, 시간은 답의 정확도를 뜻하지 않습니다.

## 25–30분: 회고

- 자료를 읽는 단계와 결과를 검증하는 단계는 어떻게 다른가요?
- 실행하기 전의 계획과 실제 결과는 화면에서 어떻게 구분되나요?
- 그룹 이름이 비어 있거나 금액을 읽을 수 없다면 왜 계산을 멈춰야 할까요?

실습에 쓰는 계산과 계획은 로컬의 결정적 코드가 수행합니다. 선택 활동의 모델 비교 결과는 계산을 실행하지 않습니다.
